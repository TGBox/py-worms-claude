# ADR-0006: Persistenz in versionierten JSON-Dateien im Nutzerdatenordner

- **Status:** Angenommen · **Datum:** 2026-10-31 · **Phase:** 0

## Kontext

Teams, Schemata, Karten, Kampagnenfortschritt, Erfolge und Optionen müssen gespeichert werden,
auch im PyInstaller-Build, in dem `assets/` schreibgeschützt ist.

## Optionen

SQLite (robust, aber nicht menschenlesbar und schwer zu teilen) gegen **JSON-Dateien** (lesbar,
teilbar, per Git versionierbar, für diese Datenmengen ausreichend).

## Entscheidung

JSON-Dateien, je Objekt eine Datei. Ablage unter `%APPDATA%\py-worms-claude\` (Windows) bzw.
`~/.local/share/py-worms-claude/`. Jede Datei hat `version` und wird beim Laden schrittweise
migriert. Geschrieben wird atomar (temporäre Datei + `replace`). Mitgelieferte Inhalte unter
`assets/` sind Vorlagen und werden nie überschrieben.

## Konsequenzen

- Teams und Schemata lassen sich als Datei weitergeben.
- Pro Dateityp ist eine Migrationsfunktion zu pflegen, sobald sich das Format ändert.
